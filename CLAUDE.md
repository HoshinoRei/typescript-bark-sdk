## Development commands

- Install dependencies: `bun install`
- Format all files: `bun run fmt`
- Format check only: `bun run fmt:check`
- Fix lint issues: `bun run lint`
- Lint check only: `bun run lint:check`
- Type check public entry and tests: `bun run check`
- Run tests with coverage + JUnit output: `bun run test`
- Run all validation gates: `bun run validate`
- Preview package contents: `bun run pack`

## High-level architecture

This package is a Bun-first TypeScript SDK for the Bark API v2.

- Public API surface is re-exported from `mod.ts`.
- Core runtime behavior is centered in `bark_client.ts`:
  - Uses instance-scoped server address (default `https://api.day.app`).
  - Wraps Bark endpoints (`/healthz`, `/info`, `/ping`, `/push`) using
    `BarkClientUrl` enum.
  - Converts transport/API failures into typed domain errors
    (`BarkResponseError`) with `BarkResponseErrorType` classification.
  - Implements encrypted push (`pushEncrypted`) by validating key/iv lengths,
    deriving mode+key size from `BarkEncryptedPushAlgorithm`, AES-encrypting the
    JSON payload, then posting ciphertext.
- Message creation is handled by `bark_message_builder.ts`:
  - Fluent builder over `BarkMessage` request shape.
  - Validates URL fields (`icon`, `url`) and throws typed `BarkMessageError`
    when invalid.
- Domain contracts live under root-level directories:
  - `types/` contains wire types.
  - `enums/` provides API constants and error/message enums.
  - `errors/` defines typed error classes used throughout the SDK.
  - `internal/` contains non-exported internal helpers and error types.

## Build and test structure

- Bun scripts are defined in `package.json` and lock dependencies in `bun.lock`.
- TypeScript compiler settings live in `tsconfig.json`.
- Formatting rules live in `.prettierrc.yml` and `.prettierignore`.
- Lint rules live in `eslint.config.mjs`.
- Bun test coverage settings live in `bunfig.toml`; the PR coverage report reads Bun LCOV in `scripts/report_bun_coverage.ts`.
- Unit tests in `tests/*.test.ts` use Bun's built-in `bun:test` runner and
  assert Bark behavior and typed error mapping.
- Coverage and JUnit outputs are generated by Bun test flags for CI
  consumption.
